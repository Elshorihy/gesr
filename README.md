# جسر | Jisr

نسخة الويب الخاصة بمشروع جسر.

## الملفات
- `web/index.html`: واجهة الويب لعرض الملفات وتنزيلها ورفع ملفات إلى الكمبيوتر.

## طريقة التشغيل
واجهة الويب الحالية تعتمد على خادم برنامج الكمبيوتر نفسه؛ افتح الرابط الذي يعرضه برنامج جسر على الكمبيوتر، أو استخدم الصفحة التي يقدمها الخادم على نفس الشبكة المحلية. لا تفتح `web/index.html` من GitHub Pages وتتوقع أن تنقل الملفات مباشرة: GitHub Pages يستضيف ملفات ثابتة فقط، بينما نقل الملفات يتم عبر خادم الكمبيوتر المحلي على نفس الشبكة.

## الأمان
التوكن مطلوب لكل عمليات الملفات. لا تشارك رابط الاتصال أو التوكن مع أشخاص غير موثوقين، وأوقف مشاركة الملفات عند الانتهاء.
